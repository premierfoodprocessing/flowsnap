Privacy Policy

Last updated: August 7, 2026

This policy explains how the current FlowSnap website and processing service handle information when you analyse and download authorised public media.

Information FlowSnap processes

When you submit a public media link, FlowSnap sends that link to its processing service so it can request media information from the source platform. The resulting analysis can include the media title, creator, duration, thumbnail, source page and available format details.

When you prepare a download, FlowSnap temporarily associates the selected format with the source page, media title and proposed filename. The browser receives opaque analysis and download identifiers instead of a direct source-media address.

Temporary retention

  • Media analyses are held in application memory for up to 10 minutes.
  • Prepared download jobs are held in application memory for up to 5 minutes and are consumed after one delivery attempt.
  • Completed files are created in isolated temporary directories and are scheduled for deletion after delivery. Failed delivery directories are also removed.
  • In-memory analyses and jobs are cleared whenever the backend restarts.

FlowSnap does not intentionally build a permanent history of submitted links or downloaded media.

Hosting and technical logs

The frontend is currently delivered through GitHub Pages and the production processing service is hosted on Render. Those providers may process standard technical information such as IP address, browser or device information, request path, timestamps and operational logs under their own policies.

The source platform also receives a server request when FlowSnap analyses or retrieves the public media link you submitted.

Clipboard access

The Paste button asks your browser for clipboard access only after you select it. FlowSnap uses the returned text to fill the link field. It is sent to the processing service only if you submit the form.

Cookies, accounts and analytics

FlowSnap does not currently provide user accounts, run application analytics, display advertising or set its own tracking cookies. This policy must be updated before any of those practices are introduced.

Sharing and sale

FlowSnap uses its hosting providers and the relevant source platform to operate the requested workflow. FlowSnap does not currently sell personal information or share submitted media details with advertising or data-broker services.

Security and responsible use

FlowSnap uses short-lived identifiers, one-time download jobs, isolated temporary directories and automatic cleanup to reduce unnecessary retention. No internet service can promise absolute security, so only submit public links you are authorised to process.

Your choices and contact

You can avoid submitting a link, close the page before preparing a download, or wait for a short-lived analysis or job to expire. For privacy questions or requests, email flowsnap.support@gmail.com. Do not include passwords, cookies or private-media links.

Changes to this policy

FlowSnap will update this page before materially changing its processing, retention, analytics, advertising, account or payment practices.
