# FlowSnap Monetisation Plan

## Objective

Develop sustainable revenue without compromising user trust, responsible use, accessibility or platform compliance.

Advertising must never be confused with navigation, format selection or download controls.

## Design Principles

- Clearly label every advertisement or sponsorship.
- Keep ads separate from Continue, format selection and download actions.
- Never imitate download buttons.
- Do not use pop-ups, pop-unders, forced redirects or misleading countdowns.
- Preserve a fast, clean mobile experience.
- Process only public content users own or are authorised to save.
- Do not circumvent digital rights management or technical protections.

## Reserved Placement Areas

Potential future placements:

1. A banner after the result card and permission notice.
2. An in-content placement between major information sections.
3. A clearly labelled footer sponsorship area.
4. A desktop-only side placement if the layout later supports it.

Advertisements should not appear inside the result card or beside a download control.

## Readiness Requirements

Before enabling advertising:

- Deploy the frontend away from GitHub Pages if FlowSnap becomes a commercial service.
- Deploy the backend securely.
- Add Privacy, Cookies, Contact and Copyright/DMCA processes.
- Implement an appropriate consent-management platform.
- Publish useful original content and responsible-use guidance.
- Review each advertising partner's current copyright and placement policies.
- Confirm that ads cannot be mistaken for site controls.

## Potential Revenue Channels

- Contextual display advertising, subject to network approval.
- Direct sponsorships from legitimate creator tools.
- Clearly disclosed affiliate relationships.
- Optional premium convenience features later.
- Voluntary support or donations.

No revenue channel should depend on deceptive behaviour or unauthorised media use.

## Implementation Phases

### Phase 1 — Architecture

Reserve neutral ad-slot components but keep them disabled.

### Phase 2 — Trust and Compliance

Complete policy pages, consent handling, content guidance and hosting migration.

### Phase 3 — Traffic Validation

Measure lawful organic usage before selecting a monetisation partner.

### Phase 4 — Controlled Activation

Enable one clearly labelled placement and measure performance, usability and policy impact.

### Phase 5 — Review

Expand only when advertising does not materially harm trust, speed or accessibility.

## Current Status

Monetisation is planned but not enabled.

FlowSnap remains focused on delivering a clean, responsible and technically reliable core workflow.
